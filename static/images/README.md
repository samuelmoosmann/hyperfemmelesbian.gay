# Images Directory

Place your Gremium member photos and other images here!

## Usage

Any images placed in this folder will be accessible at `/images/filename.jpg` in your site.

For example:
- `static/images/general-secretary.jpg` → accessible at `/images/general-secretary.jpg`
- `static/images/finance.jpg` → accessible at `/images/finance.jpg`

## Recommended Image Sizes

- **Gremium photos**: 300x300px or larger (square images work best)
- Other images: Any size, but optimize for web use

## Supported Formats

- JPG/JPEG
- PNG
- GIF
- WebP
- SVG
