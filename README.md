# Hyper Femme Lesbian Gay

A fabulous, sparkly website built with Hugo and deployed on GitHub Pages.

## Features

- Custom hyper-femme theme with pink gradients and animations
- Homepage with YouTube video embed
- Protocols page (because we're famous for them!)
- Contact page
- Fully responsive design
- Automatic deployment to GitHub Pages via GitHub Actions

## Local Development

To run the site locally:

```bash
hugo server -D
```

The site will be available at `http://localhost:1313`

## Building for Production

To build the site for production:

```bash
hugo --gc --minify
```

The built site will be in the `public/` directory.

## Deployment

The site automatically deploys to GitHub Pages when you push to the `main` branch.

To enable GitHub Pages:
1. Go to your repository settings
2. Navigate to Pages
3. Set Source to "GitHub Actions"

## Tech Stack

- Hugo v0.154.3
- Custom theme "sparkles"
- GitHub Actions for CI/CD
- GitHub Pages for hosting
